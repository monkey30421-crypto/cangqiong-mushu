# 苍穹母树本地编辑器

误删后的功能恢复版本。根据现有游戏源码、配置和资源重建，未声称找回被删除的原始界面源码。全部使用当前项目的 2D 地图与原生 Spine 资源。

## 启动

双击项目根目录的 `启动地图编辑器.command`，或本目录同名启动器。服务地址为 <http://localhost:3000>，只监听本机。需要 Node.js 22.13 或更新版本。

也可以在本目录执行 `npm ci`、`npm run dev`。构建检查运行 `npm run build`，保存与兼容性检查运行 `npm test`。

| 页面 | 地址 | 功能 |
| --- | --- | --- |
| 地图 | `/` | 主城、起点、两种普通前景、首领图；图层开关；可行走多边形；出生区域；祭坛树原点与触发区域；传送阵触发椭圆和独立特效原点 |
| 角色 | `/characters` | 主角 ID 1、怪物 101 起；名称、模型资源、X/H 体积、阴影基础比例、击退距离、是否可击飞、多条独立概率掉落 |
| 主角动作 | `/actions` | 全部 20 个动作、技能范围、前移距离/毫秒时长、命中停顿、上下层特效、原生 Spine 预览与事件时间 |
| 怪物动作 | `/monster-actions` | 每只怪物单独设置 13 类动作及上下层特效，前进/后退、击飞/倒地/躺地、原地死亡；首领技能 |
| 道具 | `/items` | 现有道具列表、名称、类型（含货币）、固定品质、图标与说明；保留隐藏装备属性 |

地图坐标与游戏一致：原图从 Y=400 裁出高度 1200 的世界，不缩放或移动原图。祭坛树预览应用游戏偏移 `(15.00003,-21)`。背景及中景显示完整地图；游戏运行时的视差由游戏镜头控制。

## 地图操作

- 左侧选择场景和编辑对象；拖动顶点或区域，右侧精确输入坐标。
- 双击多边形边线插点，右键顶点删点；至少保留三个顶点。
- 出生区拖动右下角调整尺寸，触发椭圆拖动右侧或下侧控制点调整半径。
- 滚轮缩放，中键或空格加拖动平移；“适应场景”回到完整地图。
- `⌘/Ctrl+Z` 撤销，`⌘/Ctrl+Shift+Z` 重做，`⌘/Ctrl+S` 保存。
- 导出和导入只改变编辑器内存，点击“保存到游戏”才落盘。

## 保存与备份

打开页面不修改游戏配置。点击保存时校验数据、检查外部修改冲突，并将旧文件保存在同位置的 `.bak`。每次启动还会将现有配置复制至本目录 `backups/restore-时间/`。

地图更新 `godot_demo/config/main_city_editor.json`、`dungeon_area_editor.json` 及游戏实际优先读取的用户配置：`~/Library/Application Support/Godot/app_userdata/苍穹母树：初枝试炼 Demo/` 下的 `city_walkable_area.json`、`city_spawn_area.json`、`dungeon_area_editor.json`。其余四类配置保存至项目原有 JSON，保留没有显示在网页上的字段。

保存后重新进入对应场景；模型等初始化资源建议重新启动游戏。其他页面或游戏写入了相同配置时，先“重新读取”再修改，避免覆盖新数据。

## 预览

原生 Spine 动作重复播放，角色 `action` 事件每次独立创建一次上下层特效。右侧预览始终等比适配面板宽高，窗口缩放不会把角色或特效压扁、拉长。角色与特效共用脚底原点及缩放，特效不会按自身包围框重新适配。手动“重播特效”不重启角色动作。静态 PNG 模型显示原图。

阴影大小先乘角色配置百分比，再按跳跃高度衰减：地面 100%、1H 为 40%、2H 为 0%。页面中的跳跃滑块只用于查看效果。

服务运行日志位于 `editor.log`。启动器检测到本项目服务已运行时直接打开页面，不重复开启服务。`PORT=3001 npm run dev` 可使用其他端口。

## 动画资源约定

默认只使用原生 Spine 动画；仅在用户明确单独要求时采用其他动画形式。主角模型直接选择 `.tres` 骨骼，怪物动作库也只列出原生 Spine 资源。动作时长和事件从实际骨骼源读取，特效入口为 `godot_demo/config/spine_effects.json`。不再读取或生成烘焙动作库。PNG 模型只作为静态贴图，Spine 自身的 PNG 图集仍须保留。

怪物的“击飞落地”动作可留空：留空时落地即进入“躺地循环”，不会自动选用模型的落地动画或等待默认时长；已配置时先正常播放落地动作。

动作 / 技能列表内直接显示每条技能的横向、纵向、高度范围，以及前移距离、前移时长和命中停顿；修改后使用页面顶部“保存到游戏”统一保存。参数列位于模型动画之后、上下层特效之前，每个输入框最长 56 px，六项参数始终排成一行，输入框之间固定间隔 20 px；模型动画和特效选择框固定 200 px 宽，窄窗口将预览移至列表下方，完整名称可悬停查看，无需横向滚动。

## 资源实时更新

角色配置、动作 / 技能、怪物动作的右侧预览每秒检查当前实际使用的 Spine `.tres`、骨骼源、图集和全部图集贴图。文件内容变化后自动重载，骨骼、图集和贴图使用版本化地址，避免显示旧缓存；手动“刷新资源”可立即重载。动画选项、动作时长和事件同步更新，未保存的技能参数保持原值。

如果游戏引用 `Character.spine-json`，但你从 Spine 导出替换的是同目录下较新的 `Character.json`，编辑器会验证导出后同步至游戏引用的 `.spine-json`，旧版本备份在 `backups/spine-sources/`。直接编辑且时间更新的 `.spine-json` 优先，不会被旧导出覆盖；未写完的导出等待下次检查。图集和贴图仍读取 `.tres` 实际引用的文件。游戏本身需要重新导入并重启才能使用新资源。
